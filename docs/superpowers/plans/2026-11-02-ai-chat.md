# AI chat implementation plan

> Native execution in this session; independent whole-branch review before merge.

**Goal:** Deliver compact, durable, character-aware local iOS conversations.
**Architecture:** Extend the existing JSON conversation store with optional fields and history enumeration. Isolate SSE transport/parser, session lifecycle and UI components. Add one Markdown rendering dependency at the app boundary.
**Tech Stack:** Swift 5.9+, SwiftUI iOS 16.1+, SwiftStreamingMarkdown 0.7.0.
**Spec:** `docs/superpowers/specs/2026-11-02-ai-chat-design.md`.

## Constraints

Preserve old chat/vault files; no cloud or credential migration. Exactly one answer per explicit send. Remote Markdown images disabled. Keep endpoint redirects, bounds and secret protections. Observe host resource pause.

## Review focus

Legacy/corrupt records, queued draft writes when switching sessions, cancellation and partial persistence, truncated/malformed stream success, role changes relabeling old replies.
